# Ручное добавление товаров в «Новинки»

В подборке со slug `novinki` сохраняется режим `new` и обычный срок в днях.
Состав: автоматические новинки **плюс** товары из существующего поля `products`.
Товар показывается один раз, даже если подходит по обоим правилам.

## Для менеджера

1. В Strapi открыть **Контент → Подборка товаров → Новинки**.
2. Оставить режим `new` и текущий срок автоматического показа.
3. В поле **Товары вручную** выбрать нужные карточки по названию.
4. Нажать **Опубликовать**. Сохранение черновика не меняет сайт.

Выбранные товары остаются в новинках без ограничения по возрасту.
Чтобы снять закрепление, удалить товар из поля и снова опубликовать подборку.
Если товар ещё проходит по обычному сроку, он останется до окончания этого срока.

Уценка, скрытые и недоступные для витрины товары не появляются из-за закрепления.
Отдельные варианты джиггера не нужно добавлять: выбирается основная карточка.
Обычная сортировка сохраняется: товары с фото впереди, затем дата новизны.

Поле связей Strapi ищет по **названию**, а не по артикулу. Для ОПТИК:

| Модель | Джиггер | Шейкер бостон 850 мл | Смесительный стакан 500 мл |
|---|---|---|---|
| Гипно | JigHpn | ShKorHpn | MixHpn |
| Муар | JigMr | ShKorMr | MixMr |
| Ритм | JigRtm | ShKorRtm | MixRtm |

## Реализация и публикация

Используется существующая связь `catalog-collection.products`. Новых таблиц,
заданий по расписанию и полей в МойСклад не требуется. Даты создания, цены,
остатки и синхронизация не меняются. Значок новинки учитывает ручной список
в каталоге, карточке, избранном, рекомендациях и обоих вариантах поиска.

Публичные обработчики подборок читают опубликованную запись. Черновик с другими
товарами или сроком не влияет на состав и значки до публикации.

При выпуске нужно обновить только подсказки `products` / `noveltyDays` в сохранённой
конфигурации Content Manager: схема задаёт подписи для новой конфигурации, но
Strapi сохраняет уже настроенные подписи. Не перезаписывать весь макет редактора.
Существующие права и поиск по названию сохраняются.

Добавление ОПТИК является отдельной правкой данных при выпуске: сохранить связи
черновика и опубликованной записи, добавить девять родительских карточек,
сохранить прежние выбранные товары и проверить состав. Для возврата восстановить
только изменённые связи и подсказки из снимка, затем прежний код. Нельзя откатывать
всю рабочую базу поверх новых заказов.

Проверки: `node --test tests/*.test.cjs`, `tsc --noEmit`, `npm run build`.
Поведенческие сценарии находятся в `tests/manual-novelties.test.cjs`.
